# Botão de texto

A mesma tecla com um rótulo, para ações fora da reprodução: adicionar fonte, guardar, cancelar.

## Regras
- Altura `key-sm` (28px), padding horizontal `space-3`, rótulo em `label`.
- Nunca preenchido a cor. A ação principal de um diálogo distingue-se pela posição (à direita), não pela cor.
- Rótulo com verbo primeiro, sem ponto final: "Adicionar fonte", "Tentar de novo".
- O consumidor fornece: o rótulo e a ação.
